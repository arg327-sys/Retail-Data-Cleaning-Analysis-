# Retail-Data-Cleaning-Analysis-
Excel-based retail revenue analysis project focused on cleaning a messy dataset, building pivot tables, and creating an interactive dashboard to identify revenue drivers, trends, and business insights.


**Goal:** Clean, standardize, and analyze retail transaction data to understand revenue performance across products, categories, locations, and payment methods, and to identify drivers of revenue that affect financial reporting.

**Dataset Overview:**  
- Messy dataset generated by ChatGPT
- Over 1,000 rows of retail transaction data
- Key columns:
    - Order Date (Date ordered)
    - Category (Category of ordered product)
    - Total Price (Revenue)
    - Ship State (State ordered from)
    - Order Status (Complete, Pending, or Cancelled)

**Project Components:**  
  - Goals, Interpretations, & Recommendations
  - Messy dataset 
  - Dataset Cleaning Process --> All key changes done to the messy dataset to make it clean
  - Clean dataset
  - Pivot tables --> Organize variables with revenue to understand revenue trends
  - Charts made from Pivot tables --> Visually organize Pivot table data
  - Retail Revenue Performance Dashboard --> Comprehensively organize key aspects of revenue performance


**Insights:**
- Headphones generate the highest product-level revenue
- Electronics is the top-performing category, driven primarily by headphones
- Revenue is heavily concentrated in Electronics, creating dependency risk
- New Jersey is the highest-revenue state
- Credit cards are the most commonly used payment method
- Revenue peaks in October 2023

**Recommendations:**
- Increase promotions for headphones near mid-September
- Increase suppliers for Electronics and invest in secondary categories to reduce dependency
- Introduce incentives for credit card users to increase order value
- Conduct deeper market analysis in mid-performing states
